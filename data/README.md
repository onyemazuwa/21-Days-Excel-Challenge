# Data

- `fuel_queue_messy_4weeks.xlsx` — the original messy dataset used for Days 1–3 (audit + cleaning). 711 rows, includes intentional duplicates, blanks, formatting inconsistencies, and outliers.
- `fuel_queue_cleaned.xlsx` — added after Day 3, once duplicates/blanks/formatting/outliers are resolved.

Note: this is a **synthetic** dataset built to realistically simulate crowdsourced fuel queue data across 8 Nigerian states over a 4-week period. Real submission data (via Google Form) is being collected in parallel and may be incorporated in a later phase.
